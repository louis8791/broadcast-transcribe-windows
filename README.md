# Broadcast Transcribe Windows

這是廣播音檔轉錄工作流的公開展示邊界，說明輸入／輸出契約與產品化方向。

## 公開範圍

- Windows 本機轉錄工作流的高階架構
- 可公開討論的輸入、輸出與品質責任
- 不含真實音檔、逐字稿、個人路徑、領域詞庫或內部品質修復腳本

完整執行環境、領域資產與歷史版本保存在私有核心 repo：
[broadcast-transcribe-windows-core](https://github.com/louis8791/broadcast-transcribe-windows-core)

本 repo 不是可直接執行的交付包；路徑、模型與工具位置必須由使用者在私有環境自行設定。

## 邊界說明

請參閱 [PUBLIC_SCOPE.md](PUBLIC_SCOPE.md)。公開內容不得包含真實媒體、私人路徑、領域詞庫、hallucination blocklist 或內部驗收腳本。
